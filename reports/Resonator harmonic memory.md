# Retuning stored energy tests resonant identity

**R-01 warrants a modal-led research continuation, not approval of a finished instrument.** The isolated laboratory implements chord-generating resonators, independent excitation, explicit memory policies and a competing feedback-delay architecture. Its strongest conceptual result is also a limitation: retained energy in a fixed linear system is superposition, not a new musical interaction. Differentiation must therefore come from controllable changes to that energy's tuning, damping or distribution. Rendered comparison material and engineering measurements support investigation; they do not establish a distinctive, expressive sound. **No human listening assessment or Cubase playability trial is claimed.** The accompanying [evidence record](../docs/research/r01/EVIDENCE.md) owns completed commands, measurements, listening-pack location and remaining verification limits.

## Modal coordinates make harmonic memory inspectable

Parallel modal synthesis is the leading candidate because each mode has directly controlled frequency, decay and state. A complex resonator's pole radius sets exponential decay and its angle sets frequency; it need not begin with a conventional oscillator chord followed by an effect. The prototype uses four chord tones with three quadrature modes each. Root, intervals, cents offsets, stretching and inharmonicity define the structure; an independent unpitched stream supplies energy. This implements the intended distinction between excitation and chord generation ([complex resonator theory](https://www.dsprelated.com/freebooks/filters/Complex_Resonator.html); [prototype core](../research/r01/core.cpp)).

The competing waveguide bank has four fractional-delay feedback strings per bank, with low-pass damping and first-order allpass dispersion. One string creates a family of partials, whereas the modal candidate explicitly controls three components per tone: these are competing instruments, not equal-mode implementations. Linear delay interpolation introduces frequency-dependent loss, so equal nominal decay controls do not guarantee equivalent decay. Allpass dispersion changes phase delay without fixed-coefficient magnitude loss, and the prototype compensates the fundamental's filter phase delay when choosing the string length. This is a minimal delay candidate, not a verdict on every waveguide design ([fractional-delay interpolation](https://www.dsprelated.com/freebooks/pasp/Fractional_Delay_Filtering_Linear.html); [allpass interpolation](https://www.dsprelated.com/freebooks/pasp/First_Order_Allpass_Interpolation.html); [dispersion](https://www.dsprelated.com/freebooks/pasp/Stiff_String_Synthesis_Models.html)).

The modal bank offers precise partial damping, stretched structures and bounded inter-tone coupling. The delay bank offers richer implicit partial families but tuning/decay depend on interpolation and loop filters; it does not implement modal coupling, individual partial damping or Partial memory. A dense coupled physical mesh was rejected for this stage: it adds parameters and ambiguous stability ownership before the smaller system earns musical interest. Combining both architectures into a permanent “quality” switch is likewise unjustified. Measured CPU, memory and tuning tradeoffs belong in the evidence record, not textbook operation-count estimates.

The laboratory remains framework-independent C++20 with a separate executable; Sequence and Field are linked only for comparisons. No existing product DSP, public parameter identifiers, plugin identity or session format is introduced. The repository's separation between DSP, host boundary, research and listening provides reusable conventions rather than permission to bypass evaluation ([research policy](../docs/DSP_RESEARCH.md); [listening protocol](../docs/testing/LISTENING.md); [experimental types](../research/r01/core.hpp)).

## Memory policies change what survives a chord

**Shared state does not preserve an independently sounding old chord.** It retunes existing coordinates or delay history into the new structure and adds subsequent input there. Reset clears the current bank before a strike. Partial, available only for modal synthesis, scales coordinates by the square root of the retained-energy fraction before retuning; retaining one quarter of energy means retaining one half of amplitude. Overlap preserves the previous bank's tuning and excites a second bank, replacing the oldest target on a later strike. This two-bank limit is explicit and stealing is counted. Coupling is separate from voice allocation: orthogonal rotations transfer modal energy across chord tones under any supported memory policy ([state transitions](../research/r01/core.cpp)).

The fixed-linear null test compares two excitations through one shared bank with the sum of independent renders. Its agreement is a deliberately negative differentiation result: **shared memory alone is not meaningfully different from overlapping linear responses**. Fixed linear coupling also remains a linear system, even if its eigenmodes change. Retuning retained coordinates, partial damping and time-varying transfer are the candidate performance mechanisms; persistent safety limiting is a different, nonlinear mechanism and must be disclosed rather than credited to passive resonance ([modal state-space theory](https://www.dsprelated.com/freebooks/pasp/State_Space_Modal_Synthesis.html); [null and memory tests](../research/r01/tests.cpp)).

Experimental ownership is concrete. The processing thread owns both banks, delay history, accepted chord and event order; preparation allocates delay storage. Topology and memory policy are chosen at preparation. Controls use validated physical values, not stable automation IDs. At most 64 sorted, sample-offset events are accepted per callback; malformed batches are rejected, invalid controls retain the previous valid values, and input sanitation is counted. Events at one sample are handled together before that sample's excitation; Panic takes precedence. A strike changes memory/tuning but does not itself synthesize the input burst. This separation permits a retune without re-excitation ([core contract](../research/r01/core.hpp); [event processing](../research/r01/core.cpp)).

The MIDI experiment accepts up to four held notes within two octaves, coalescing same-sample changes into one chord transition. The last note-off releases persistence rather than silently deleting history. Snapshot root/interval control additionally supports cents offsets and deterministic mutation. These are bounded offline semantics, not a finished MIDI adapter: velocity, sustain pedal, MPE, host automation ordering, transport recall and DAW ergonomics remain unproven. Session compatibility must eventually choose explicitly between empty-history recall and captured-state restoration; this experiment supplies neither serializer nor portable captured memory. Field's existing control-state restoration does not serialize its delay history either ([Field state format](../docs/products/field/STATE_FORMAT.md)).

## Bounded energy is not proof of transparent persistence

For modal state vector z, an unforced update can be written as QDRz: Q and R are orthogonal coupling/frequency rotations and D contains damping radii. Thus ‖QDRz‖ ≤ r_max‖z‖. The autonomous bound survives changing orthogonal rotations; it is stronger and more relevant than assuming every arbitrary resonant-filter implementation is stable. With input, however, a bound scales with input magnitude divided by 1−r_max. At unit radius, coherent excitation can accumulate indefinitely. **Lossless unforced behavior does not imply bounded continuously driven behavior** ([lossless mixing](https://www.dsprelated.com/freebooks/pasp/Choice_Lossless_Feedback_Matrix.html); [implemented update](../research/r01/core.cpp)).

The modal prototype therefore caps each bank's squared-coordinate norm at 16 by radial scaling and counts interventions. Delay-line writes are bounded separately. Both architectures sanitize non-finite input and bound excessive drive; these guards are audible nonlinear design choices when active, not evidence of an unmodified stable response. Modal state norm and summed delay-buffer energy have different meanings and cannot be compared as physical joules or perceived loudness. Delay persistence also retains interpolation/filter losses: it is not equivalent to the modal unit-radius case. Fixed-coefficient allpass theory does not independently prove safety during abrupt coefficient changes.

Correctness checks cover analytic modal response, amplitude-T60 decay, memory fractions, superposition, changing coupling, sample-offset events, callback partition invariance, input rejection, clearing history and driven bounds. Allocation and operating-system audit probes calibrate their own detection before checking processing. Measurements span the repository's six standard rates, 44.1–192 kHz, with irregular blocks; the evidence record distinguishes actually executed checks from future coverage. There is no callback allocation, lock, filesystem or logging path in the core, but a local audit and measured workload are not proof of every platform's deadline behavior ([tests](../research/r01/tests.cpp)).

The alias diagnostic uses a 4.5 kHz sinusoidal input at low and strong drive, measures predicted folded-harmonic bands, and compares with a four-times-rate render filtered by a 129-tap Blackman-windowed low-pass before decimation. Guard counts accompany those measurements. High-frequency noise energy is not itself aliasing, and differences between rates include interpolation, damping, excitation scaling and nonlinear operating-point differences. Consequently this is a **restricted fold-band diagnostic, not a comprehensive alias floor**. Time-varying retuning/coupling sidebands and broad automation sweeps need separate analysis. Oversampling is deferred until the offending stage and a meaningful improvement are established; a blanket oversampling dependency would obscure the research question ([measurement implementation](../research/r01/lab.cpp)).

## The comparisons test mechanisms, not musical success

R1 uses white, approximate pink, spectrally shaped noise, impulse, short granular-noise bursts and a declared synthetic external-input transient. R2 compares modal and waveguide candidates with identical stored excitation streams, rather than assuming equal random seeds imply equal inputs. Bursts are normalized to equal squared-sample energy; raw outputs remain available alongside obscured, RMS-matched listening files. RMS matching is not perceptual loudness equivalence. The external-input fixture demonstrates the DSP boundary, not imported recordings or live audio routing ([renderer](../research/r01/lab.cpp)).

R3 contrasts harmonic, stretched and inharmonic arrangements with minor, suspended, extended and ambiguous four-tone structures. R4 contrasts uncoupled and coupled modal banks. R5 compares Reset, Shared, Partial and bounded Overlap, including a fixed-coefficient superposition control. R6 includes chord snapshots, microdetuning, seeded repeated mutation and sample-offset MIDI replacement. R7 probes short decay, long retention, persistence/release and strong excitation. These fixtures expose mechanisms and failure conditions; an eight-second musical example cannot establish an entire long-decay envelope. The evidence record identifies longer stress coverage and its limitations instead of treating nominal settings as completed observations.

R8 takes the existing family seriously. Sequence is monophonic, so the chord reference uses **four independent Sequence instances summed into one Field**, not a single instance reduced to its last note. A second reference sends the same noise stream into Field. Field already has an eight-line moving feedback network, retained energy, saturation and fifth/octave pitch returns; it is not memoryless reverb. Its MIDI exciter injects a tuned sinusoid rather than tuning the network to arbitrary chord intervals. R-01's measurable structural distinction is direct control of the resonating generator's harmonic relationships and retained-state transitions, not the invention of stored energy ([Sequence specification](../docs/products/sequence/SPECIFICATION.md); [Field DSP](../apps/field/field_processor.cpp)).

Rendered differences cannot establish that these capabilities are difficult to reproduce with existing products. The next assessment must use both matched examples and a composition task: create a short stab and an evolving retained-energy phrase, predict a chord transition, repeat it, then recreate the useful result with Sequence→Field. Record preference/confidence separately from edits, time, automation complexity and mistakes. “No reliable difference” is a valid finding. Require a repeatable benefit across contrasting phrases, not one attractive preset or a louder example. This protocol remains **unperformed**, with no invented listening judgments ([research notes](../research_notes/Resonator%20harmonic%20memory/architectures.md)).

## The interface exposes causes before parameters

R9 supplies two static wireframes and an interaction specification, not a running editor. One screen separates excitation, four-tone harmonic structure and the consequence of the next strike. Selected-mode detail supplies exact frequency/cents/damping without twelve permanent channel strips. Shared and Overlap display different meanings: retuned current energy versus separately surviving banks. A waveguide view must show four line-energy summaries, not fabricated modal bars. Grayscale hierarchy, explicit focus, numeric entry and meaningful state feedback preserve the family identity without selecting a finished product accent ([interface study](../docs/research/r01/INTERACTION.md); [Aste UI system](../docs/UI_SYSTEM.md)).

The proposed minimum is one selected resonator architecture, four-tone structure, a restrained exciter selector, excitation amount, Decay, Damping, bounded Coupling, explicit memory behavior and Clear Energy. Root/interval/cents and individual damping live in progressive detail. Keyboard alternatives, accepted/rejected value feedback, text energy summaries, reduced motion and bounded meter updates are specified; native scaling, VoiceOver and Cubase shortcut behavior remain untested. The audio thread would publish coherent fixed-size snapshots to a UI handoff, never expose mutable state directly. No such concurrent handoff or stable parameter mapping is claimed by the static study.

## Conclusion

The next investment should test whether a person can intentionally move surviving energy between harmonic structures without detailed mode engineering. Preserve the waveguide candidate and Sequence→Field as controls, but avoid a hybrid engine, large chord library, modulation matrix or decorative physical simulation before that question is answered. Adding dub delay to an oscillator chord would evade it entirely.

Proceed only if assessed audio and repeatable control tasks establish a benefit that survives level matching and the family comparison. If retuning is merely an unwanted pitch bend, coupling requires obscure tuning, or ordinary overlapping tails suffice, retain the laboratory and stop product development. That outcome would satisfy the research goal more honestly than shipping a technically interesting but musically redundant plugin.
