# Impulse I-01 music-machine test

Record host build, Mac, architecture, sample rate, buffer, and result.

1. Load as a stereo and mono VST3 instrument in Cubase and Ableton.
2. Verify pitch classes C through G in multiple octaves trigger Kick, Click,
   Burst, Body, Low, Crack, Metal, and Cut.
3. Program Off, Hit, and Accent states in every visible row, reopen the project,
   and verify the exact pattern returns.
4. Run differing track lengths through start, stop, locate, host loop, tempo
   change, and project reopen.
5. Compare real-time, offline, freeze, and repeated bounces with the same seed;
   compare again after changing seed.
6. Exercise 1/8, 1/16, and 1/32 divisions, all ratchets, timing extremes,
   probabilities, conditions, and mutation.
7. Check a centered deep Kick and Low in mono, polarity, and repeated-hit phase.
8. Listen to Click/Burst/Crack/Metal/Cut aliasing at 44.1 and 192 kHz.
9. Automate all parameters rapidly and inspect finite output, discontinuities,
   CPU, and host synchronization.
10. Test full mixes, ambient beds, bass-heavy playback, and sparse click/cut
   arrangements without external sample layering.
11. Check scaling, Retina rendering, exact entry, keyboard focus, presets, and
    window reopen behavior.
