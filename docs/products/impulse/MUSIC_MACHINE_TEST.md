# Impulse I-01 music-machine test

Record host build, Mac, architecture, sample rate, buffer, and result.

1. Load as a stereo and mono VST3 instrument in Cubase and Ableton.
2. Verify MIDI C/C#/D/D# in multiple octaves trigger Kick/Click/Burst/Body.
3. Run default 15/23/11/16 cycles through start, stop, locate, host loop, tempo
   change, and project reopen.
4. Compare real-time, offline, freeze, and repeated bounces with the same seed;
   compare again after changing seed.
5. Exercise 1/8, 1/16, and 1/32 divisions, all ratchets, timing extremes,
   probabilities, conditions, and mutation.
6. Check a centered deep Kick in mono, polarity, and repeated-hit phase.
7. Listen to Click/Burst aliasing at 44.1 and 192 kHz.
8. Automate all parameters rapidly and inspect finite output, discontinuities,
   CPU, and host synchronization.
9. Test full mixes, ambient beds, bass-heavy playback, and sparse click/cut
   arrangements without external sample layering.
10. Check scaling, Retina rendering, exact entry, keyboard focus, presets, and
    window reopen behavior.
