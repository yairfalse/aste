# Impulse: clicks and subs

2026-11-15. Follow-up to the six-instrument revision at `5868c9c`.
User direction: the drum machine needs to be more about clicks and subs.
The earlier Space snapshot reduced activity but still used Kick and Crack.
This revision changes the starting vocabulary, not the eight-engine DSP graph.

## Implemented

New instances select **Clicks / sub**. Click plays on steps 4, 8 and 15;
Low plays on 1 and 11. Eleven of sixteen event positions are empty. Those
empty cells do not force silence while a sub tail is decaying. Energy is 18%,
variation/mutation zero, probability 100%, and all tracks share sixteen steps.

| Scene | Transient | Low-frequency object |
|---|---|---|
| Clicks / sub, index 6 | Click: 3200 Hz, 5 ms Decay, Level 50%, Tone 50%, Drive 0 | Low: 42 Hz, 260 ms Decay, Level 90%, Tone/Drive 0 |
| Cuts / pressure, index 7 | Cut: 5600 Hz, 8 ms Decay, Level 40%, Tone 18%, Drive 0 | Low: 36 Hz, 380 ms Decay, Level 90%, Tone/Drive 0 |

Both scenes use the same event positions, Output -6 dB and seed 1701. Other
rows are empty, but their engines remain available. MIDI notes 37, 40 and 43
trigger Click, Low and Cut respectively. No extra voice, effect, modulation
control or dependency was added. In particular, this is not the N-01 redesign.

The editor opens on Click. Choosing either new scene opens its active transient
controls. LOW / SUB clarifies the low-frequency role without renaming stable
parameter IDs. Selection remains silent; AUDITION is explicit and cycle controls
remain behind RHYTHM DETAILS. The [minimum-size render](impulse-minimum.png) was
generated by the real JUCE editor after selecting Clicks / sub and inspected
for clipped labels and overlap. This is not a Cubase screenshot.

## Compatibility

The previous six snapshots retain their indices, names, parameter values and
behavior choices. Space remains at index 5. State schema 4, all 368 IDs/ranges,
host reset defaults and DSP behavior are unchanged. A scene is saved as its
parameter values, not its menu index; existing schema-4 adapters understand the
new scenes' state contract. No new migration is introduced by this follow-up.
Older schemas still restore their historical defaults and behavior.

The other five instruments are untouched. Previously exported six-instrument
packs remain historical and have not been overwritten. New Impulse files use
separate `impulse-click-sub` archive names. No PR, installation, main merge,
version selection or release is part of this work.

## Rendered evidence

The offline lab uses the same new snapshot definitions as the plugin, and the
unchanged production Impulse processor. It renders two cycles at 100 BPM,
stopping new events at 4.8 seconds and allowing tails to eight seconds. Four
pattern files are independently K-weighted/gated loudness matched to -23 LUFS,
with shared sample-peak headroom capped at 0.8. They differ by less than
0.000001 LU in this meter. The method is not external meter certification,
true-peak protection or human loudness judgment.

| File | Comparison purpose |
|---|---|
| `01_previous_space.wav` | Previous sparse Kick/Crack starting point |
| `02_clicks_sub.wav` | New starting point |
| `03_cuts_pressure.wav` | Alternate edge and deeper/longer Low, same rhythm |
| `04_previous_voices_same_rhythm.wav` | Previous Kick/Crack sounds placed on the new scene's event times |

Compare 02 with 04 to separate the changed sound vocabulary from changed event
placement. Compare 02 with 03 for the two new sound balances. Four additional
isolated-object WAVs are four seconds long, played at unity MIDI velocity with
the scene's Level/Output settings; **they are not individually loudness matched
and are not extracted pattern stems** (ordinary sequencer hits use velocity 0.7).
All eight WAVs are
48 kHz stereo Float32. Two complete exports were byte-identical, including CSVs.

Actual [object measurements](evidence/objects.csv):

| Object | Time containing 95% of energy | Settled spectral peak | 20–100 Hz share |
|---|---:|---:|---:|
| Clicks / sub: Click | 5.94 ms | Not used | Not used |
| Clicks / sub: Low | 410.96 ms | 42.48 Hz | 99.07% |
| Cuts / pressure: Cut | 9.63 ms | Not used | Not used |
| Cuts / pressure: Low | 604.88 ms | 36.62 Hz | 98.95% |

Settled spectra use the existing 32768-point Hann-windowed mid-channel FFT
starting 40 ms after excitation, at 48 kHz. Peak-bin spacing is 1.465 Hz: these
are FFT-bin readings, not tuning errors. The band share excludes the initial
pitch/edge transient and is not a measurement of the whole hit. Energy-time
measurements use the complete four-second isolated render.

[Pattern measurements](evidence/patterns.csv) preserve raw levels and hashes.
The new scenes are quieter before matching than the previous Space snapshot;
their intended weight is low-frequency concentration, not added loudness.

## Checks and limits

The new-start plugin assertions were run before implementation and failed;
[the output is retained](evidence/before-tests.txt). They now check the actual
Click/Low pattern, empty competing rows, short envelope controls, old Space
recall, unchanged parameter count, byte-stable new-scene state recall, and
visible active controls after selecting each scene. Existing callback allocation,
lock/I/O, state fuzz and editor checks remain enabled.
A deliberate UI fault selecting Click for the Cut scene fails the active-control
test; [the failure is retained](evidence/ui-negative-control.txt). The correct
Cut selection was restored before final verification and packaging.

The standalone sound contract covers both scenes at 44.1/48/88.2/96/176.4/192 kHz:
settled sub power above 90% in 20–100 Hz, spectral peak in 30–48 Hz, sub energy
duration 150–800 ms, transient energy duration below 20 ms, mono output and
exact 127/511-frame MIDI partition equality. A deliberately wrong 160 Hz sub
fails the spectral contract; [its failure is retained](evidence/negative-control.txt).
These are physical bounds for this direction, not musical acceptance thresholds.

The [declared checks](../../../research/click-sub/sykli.json) cover the existing
functional suite, Impulse core sanitizers and the new offline sound checks with
ASan/UBSan. Exact-commit receipts are written to `build-click-sub-evidence/`.
The full native plugin run passed **67/68** checks; the sole failure remains
the dependency-security review expired as of 2026-11-07. It has not been waived;
the [complete test output](evidence/full-tests.txt) retains that failure.

No listening preference or actual Cubase validation is claimed. Low still has
its existing brief pitch/edge transient, saturation and monophonic retrigger;
it is not a newly designed pure sub oscillator. Click/Cut remain the existing
hard-edged oscillators, not newly band-limited synthesis. The graph's existing
sample-rate-dependent transient details and aliasing are not solved by a preset.
Listen for whether the small attacks and low body give the intended identity;
numerical concentration alone cannot answer that.

## Reproduce

```sh
cmake -S research/click-sub -B build-click-sub -DCMAKE_BUILD_TYPE=Release
cmake --build build-click-sub --parallel 3
build-click-sub/click_sub --check
build-click-sub/click_sub --fault   # must exit 1
build-click-sub/click_sub --pack build-click-sub-audio-new
```

Exports require a new directory. `-DCLICK_SUB_SANITIZERS=ON` enables ASan/UBSan.
No audio device, JUCE, filesystem operation in processing, or external audio
source is needed. WAV/FFT/meter helpers reuse `research/quality/audio.hpp`.
